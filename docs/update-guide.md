# Обновление приложения

Статус: **D4-A и D4-B закрыты; D4-C реализован, но exact-head/exact-package проверка и lifecycle closure ещё не завершены**.

Нормативный контракт: `docs/decisions/0020-d4-update-safety-contract.md`.

Этот файл пока **не является инструкцией о готовом обновлении продукта**. D4-A и D4-B закрыты; D4-C уже реализует понятный read-only статус и фиксированные packaged failure-сообщения, но его exact-head/exact-package проверка и lifecycle closure ещё не завершены. D4-D остаётся неавторизован.

Принятый будущий пользовательский сценарий:

```text
закрыть старую версию
→ временно сохранить старый пакет
→ открыть новый пакет
→ дождаться безопасной проверки совместимости и, если нужно, обновления БД
→ убедиться, что программа успешно запустилась
→ только после этого удалять старый пакет
```

D4-A уже требует, чтобы база от более новой/неподдерживаемой версии программы была отклонена до backup и миграции. Только отсутствие канонического файла базы считается первым запуском.

Важно: старый пакет не является автоматическим откатом после успешного обновления схемы. Если база уже новее старой программы, старая программа должна отказаться от запуска до изменения данных.

D4 не включает автоматическое скачивание обновлений, GitHub Releases, установщик, DMG, подпись, notarization или App Store.
